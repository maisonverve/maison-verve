HOW TO PUBLISH EACH ISSUE
  1. Load your existing magazine.json above.
  2. Fill in the new issue and add your articles.
  3. Click Download updated magazine.json.
  4. Open your GitHub website repository, select magazine.json, click the pencil icon to edit, replace its contents with the contents of your downloaded file, and commit. Alternatively upload the replacement file through GitHub's interface.
  5. After GitHub Pages redeploys, your new issue appears on the homepage and all earlier issues remain in the archive.

This is a static-site editor. It cannot publish to GitHub automatically and it does not save drafts to a server. Keep a copy of the downloaded JSON.
